Teio

A gamified STEM app for grades 7–12 — skill trees, streaks, hearts, badges, and a local AI tutor, built to run entirely on your own machine.

MathScienceTechnologyEngineering
🔥

Duolingo-style skill trees

XP, hearts, daily streaks with a freeze, and badges — one full lesson unit per subject.

🤖

Local AI tutor

Runs on a small model through Ollama on your own machine — Socratic hints, not just answers, and never phones home.

🔒

No cloud, no login

SQLite on disk, no account, no payment processing. Free/Pro/Max tier logic is real, just defaulted to Max for your own copy.

Run it yourself

This page is a static showcase — the real app needs a server (for the database and AI tutor), so it runs locally rather than being hosted here.

git clone https://github.com/gabdeguzman2022-jpg/teio.git
cd teio
npm install
npm run dev

Then open http://localhost:3000. Full setup (including the optional AI tutor) is in the repo's README.
